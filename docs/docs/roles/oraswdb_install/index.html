Requirements

  • Minimum Ansible version: 2.14.0

Default Variables

autostartup_service

Force a chopt operation in ORACLE_HOME.

This is needed, when an existing ORACLE_HOME had multiple switches between on/off for an option.

Default value

autostartup_service: false

autostartup_service_dependency

Configure autostartup service to require and be started after this service.

Only used when autostartup_service is true.

Default value

autostartup_service_dependency: network.target

configure_oracle_profile

Create .profile_-environment scripts for databases in oracle_databases.

Mandatory when listener_installed is defined and autostartup_service: true. Otherwise the listener will not start!

Default value

configure_oracle_profile: true

glogin_default_cdb

content of glogin.sql for CDB/PDB databases

Default value

glogin_default_cdb:
  - define gname=idle
  - column global_name new_value gname
  - set heading off
  - set termout off
  - col global_name noprint
  - select upper(sys_context ('userenv', 'instance_name') || ':' || sys_context('userenv',
    'con_name')) global_name from dual;
  - set sqlprompt '_user @ &gname:>'
  - set heading on
  - set termout on
  - set time on

glogin_default_nocdb

Default value

glogin_default_nocdb:
  - set sqlprompt "_user @ _connect_identifier:>"
  - set time on

hostgroup

hostgroup: '{{ group_names[0] }}'

hostgroup_hub: '{{ hostgroup }}-hub'

hostinitdaemon

oracle_ee_options

Default value

oracle_ee_options: "{{ _oracle_ee_opiton_dict[db_homes_config[dbh.home]['version']]
  }}"

oracle_sw_image_db

Formerly, this dict was defined directly as vars/_oraswdb_install_oracle_sw_image_db, where it still will be copied to for compatibility reasons
